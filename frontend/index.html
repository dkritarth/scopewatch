Reviewer access

This demo gateway requires a reviewer token for mutating actions (submitting a simulated action, resolving an approval). Reading runs, events, and evidence needs no token. Paste the token from the submission's testing instructions. It is held in memory for this page only, never written to storage, never shown again, and sent only as the X-Reviewer-Token header and the demo compatibility header on mutating requests. Agent credentials cannot resolve approvals or reset the demo.

No token set: mutating actions are refused by the demo gate. Reading runs, events, and evidence still works.
