# Project website

The static site published to GitHub Pages at https://dkritarth.github.io/scopewatch/ by `.github/workflows/pages.yml`.

| File | What it is |
| --- | --- |
| `index.html` | Landing page: problem, pipeline, the injection scenario, invariants, evaluation numbers, Nebius and NVIDIA usage, quick start |
| `demo.html`, `assets/demo.js` | Interactive replay of invoice scenarios 01–06, one pipeline stage at a time |
| `assets/demo-data.json` | What the real gateway recorded for those scenarios, generated by `scripts/export_site_demo.py` |
| `assets/site.css`, `assets/site.js` | Shared styles and page behaviour. No build step, no framework |
| `assets/screenshots/` | WebP copies of `docs/images/screenshots/` |

The demo page computes nothing. Every decision, audit verdict, and receipt comes from `demo-data.json`, which the exporter produces by seeding the scenarios into a throwaway database with the offline `mock` provider. It also re-runs the deterministic policy engine alone on each action, so the page can show what policy said before the auditor escalated. Approve and Deny on the page only describe what the gateway would do next and are never sent anywhere.

Regenerate the data after changing the gateway or the scenarios. CI fails when the committed copy is stale:

```bash
python3 scripts/export_site_demo.py
```

Preview locally (the demo page fetches JSON, so it needs HTTP rather than `file://`):

```bash
python3 -m http.server 8765 --directory site
```
